# Smart Shipping Calculator 🚚📦

A simple Python program to calculate shipping costs based on:
- Distance (in kilometers)
- Package weight (in kilograms)
- Item type (Glass, Plastic, Wood, Paper, Iron)

This project demonstrates the use of:
- Functions
- User input handling
- Conditional statements (`if-elif-else`)
- Basic arithmetic operations

---

## 🔧 How It Works
1. The program asks the user to enter:
   - Distance in kilometers
   - Package weight in kilograms
   - Item type (choose from G, PL, WD, PI, IT)
2. Based on the item type, a cost multiplier is applied.
3. The final shipping cost is calculated as:
DOLLERS
